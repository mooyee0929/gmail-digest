# Privacy Policy

Gmail Digest is a private tool used only by its author on the author's own
Google accounts.

- It reads email metadata and content solely to generate a summary that is
  stored locally on the author's computer.
- No data is transmitted to, stored by, or shared with any third party, and
  no data is sold.
- Google user data is used only to provide the summary feature described above,
  in accordance with the Google API Services User Data Policy, including the
  Limited Use requirements.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
